You must tell HMRC as soon as possible if you believe you no longer need to send a tax return.

HMRC needs time to review your request before the Self Assessment deadline of 31 January.

! Warning You may have to pay a penalty if you do not tell them early enough.

When you no longer need to send a tax return

Examples of why you might no longer need to send a return include:

  • you’ve stopped being self-employed
  • you no longer rent out property
  • you no longer pay the High Income Child Benefit Charge

You can check if you need to send a tax return if you’re not sure.

Tell HMRC

Use this online service to tell HMRC you:

  • no longer need to send a tax return (for example, because you no longer need to pay the High Income Child Benefit Charge)
  • do not need to send a tax return for a previous tax year

You can also use the service to tell HMRC you’ve stopped being self-employed.

You need to sign in to tell HMRC. If you do not already have sign in details, you’ll be able to create them when you sign in for the first time.

Start now

There’s a different way to tell HMRC if you want to stop paying the High Income Child Benefit Charge through Self Assessment and start paying the charge through PAYE.

If you cannot use the online service

You can phone or write to HMRC to tell them you no longer need to send a return.

If you’re an agent

You cannot use the online service if you are an agent, you should phone or write to HMRC to tell HMRC your client no longer needs to send a return.

What happens next

HMRC will tell you if you need to send a tax return.


# A prototype for testing changes to travel advice and guide pages, addressing the duplicate h1 issue

A prototype to test changes to the travel advice and guide pages, addressing the duplicate H1 issue identified in previous DAC audits as both a usability issue and a WCAG Level A accessibility issue.

The prototype explores solutions, including the NHS mini hub pattern: https://service-manual.nhs.uk/design-system/patterns/mini-hub.
